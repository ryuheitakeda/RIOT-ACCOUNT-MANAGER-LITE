# Windows 検証

## 自動検証

配布フォルダーで PowerShell から実行します。実アカウントや OP.GG との通信は使わず、一時フォルダー、生成したダミー値、OP.GG を模した応答だけで検証します。

```powershell
$report = Join-Path $PWD "self-test-report.txt"
$test = Start-Process .\RiotAccountsLite.exe -ArgumentList @("--self-test", "`"$report`"") -Wait -PassThru
Get-Content $report
$test.ExitCode
```

終了コード `0` と各項目の `PASS` を確認します。失敗時は終了コード `1`、該当項目に `FAIL` と例外型が出ます。秘密情報はレポートに出しません。

レポートの保存先に、メイン画面の `self-test-empty.png`・`self-test-sample.png`・`self-test-refresh.png`（1000 × 700）と、追加・編集画面の `self-test-account-add.png`・`self-test-account-edit.png` も出力します。架空のデータを描画したもので、ユーザーのデスクトップや実データは撮影しません。

- Windows DPAPI（CurrentUser）で暗号化・復号でき、改変データの復号が拒否される。フル版のエントロピーでは復号できず、保存先フォルダー名が `RiotAccountsLite` である。
- SQLite のスキーマのバージョンが 1 で、保存したアカウント・ログイン情報・ランクを再接続後も読める。管理名だけの編集でログイン情報とランクを維持し、ログイン情報の変更を保存できる。
- SQLite 本体・WAL を含む関連ファイルに、ダミーのログイン ID・パスワードが UTF-8 / UTF-16 の平文で含まれない。
- アカウント削除で、ログイン情報と保存済みランクも削除される。
- メイン画面と追加・編集ダイアログを、空データとダミーの保存済みデータで構築でき、ランク・勝敗・取得時刻の表示が期待どおりになる。表示・フォーカス・入力操作は行わない。
- OP.GG を模した応答で「全ランク更新」を実行すると、見つからないアカウントがあっても残りを更新し、取得できなかった理由を一覧とステータスに表示する。通信先は `lol-api-summoner.op.gg` だけである。
- 検証終了後に一時データを削除できる。

## 手動確認

- アカウントの追加・編集・削除と、再起動後も登録順が維持されること。
- 「パスワードをコピー」の30秒後にクリップボードが消去されること。その間に別の内容をコピーした場合は消去されないこと。
- 「OP.GGで開く」で、選択中アカウントの OP.GG ページが既定のブラウザで開くこと。
- 「全ランク更新」で、実在するアカウントのランクが OP.GG のページと一致すること。存在しない Riot ID のアカウントを1件混ぜても残りが更新され、理由が一覧に表示されること。
- 更新中の「中止」と、更新中にウィンドウを閉じた場合に、処理が止まってから閉じること。
- `logs\diagnostics.log` に Riot ID・OP.GG 側の ID・ログイン情報が含まれないこと。
- フル版のデータ（`%LOCALAPPDATA%\RiotAccounts`）が変更されていないこと。
